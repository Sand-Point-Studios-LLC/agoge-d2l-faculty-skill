PowerPoint templates.

Put your own .pptx template in this folder, then tell the agent
"Use my template, [file name], for slides from now on." The agent will remember
it in class-standards.json (key: pptx_template).

No template here? The agent will say so and offer HTML or a content draft instead.

Never edit your template file itself. The agent builds new slides FROM a template
and leaves the template unchanged.
