# Agoge D2L Faculty Skill

An AI-agent skill and starter kit that helps faculty roll a Brightspace (D2L) course forward to a new term.
Give it a course export; it updates dates, audits quiz settings against your class standards, flags
accessibility problems, and builds an import package you review before anything goes live.

Open source from [Sand Point Studios](https://sandpointstudios.ltd) under the Apache License 2.0.
Guide and articles: **https://agoge-d2l.sandpointstudios.ltd**

## What is here

| Path | What it is |
|---|---|
| `skill/d2l-rollforward/` | The skill: `SKILL.md` and standard-library Python scripts (`rollforward.py`, `package_checks.py`, `course_report.py`, `diff_exports.py`, ...). Works with Claude Code, Codex and other agents that read skills. |
| `kit/` | The folder a faculty member downloads: `AGENTS.md`, `put-export-here/`, `work/`, `ready-to-import/`, templates, examples. |
| `standards/` | The reverse-engineered D2L import-package format, settings catalog and the class-standards interview. The skill's `references/` are built from these. |
| `site/` | Source for the guide website (plain HTML, no scripts). |
| `GUIDE.md`, `QUALITY-CHECKS.md` | How it works and what it checks. |

## Build

```bash
python3 build_kit.py          # writes the kit, skill and plugin zips (not committed)
python3 site/build_site.py    # writes site/dist/
python3 -m unittest discover -s skill/d2l-rollforward/scripts -p 'test_*.py'
```

`skill/d2l-rollforward/references/` is generated by `build_kit.py`; test the kit as built, not only from source.

## Privacy

The agent reads whatever files it opens, including quiz questions and answer keys. Never put student
data (rosters, gradebooks, submissions) in the export folder. See the site's Privacy page.
