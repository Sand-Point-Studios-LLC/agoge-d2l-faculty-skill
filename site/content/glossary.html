Glossary

Export
The zip file D2L gives you when you export a course.
Package
The zip the tool builds from your export, ready to import.
Shell
A course in D2L. A new shell is an empty course for a new term.
Agent
The AI helper in the ChatGPT or Claude app. It reads your files and runs the tool for you.
Skill
A set of written instructions and tools the agent reads. This kit is one.
Codex
OpenAI’s coding agent. You use it inside the ChatGPT app (or in VS Code if you prefer).
Claude Code
Anthropic’s coding agent. You use it inside the Claude app (or in VS Code, or a terminal, if you prefer).
Manifest
The list inside a package that tells D2L what each file is and where it goes.
Bank
A pool of quiz questions that a quiz draws from.
LTI
The way a publisher’s tool plugs into D2L and returns grades.
Opens, due, closes
D2L’s three dates for an item.
Standards
Your own choices for how your courses work. The agent saves them in class-standards.json. Only some are checked against your quizzes; the rest are remembered but not enforced. See what the kit checks.
