Set up with VS Code instead

Most people should use the ChatGPT app route. Use this page only if you already work in VS Code and prefer it. The kit works the same either way.

You do this once. Plan on 30 to 45 minutes, plus the download. If anything below does not look like what is on your screen, stop and open an issue on GitHub.

1. Sign in to ChatGPT with your MSU account

  1. Go to chatgpt.com and sign in with your MSU login.
  2. If it asks which workspace, choose the MSU one.

You do not need GitHub or Copilot for any of this.

2. Install VS Code

  1. Go to code.visualstudio.com and download it for your computer.
  2. Install it and open it.

3. Install the Codex extension

  1. In VS Code, click the Extensions icon in the left bar (four squares).
  2. Search for Codex and install the one published by OpenAI.
  3. A Codex panel appears on the right, next to a Chat tab. Use the Codex tab. The Chat tab belongs to Copilot, which you do not need.

3b. Install Python (the kit’s tools run on it)

  1. Windows: open the Microsoft Store, search Python 3.13, click Get.
  2. Mac: go to python.org/downloads, click the big yellow Download Python button, open the file and click Continue until it finishes.
  3. To check, ask the agent (once the folder is open, step 6): “Is Python 3 installed? Tell me the version. On Windows, also install the tzdata package.” The tzdata package lets the date shift keep 11:59 PM at 11:59 PM across daylight saving, and the kit will refuse to move dates without it.

4. Sign in

  1. In the Codex panel, click Sign in with ChatGPT.
  2. Use your MSU login in the browser window that opens.

5. Get the kit

  1. Download rollforward-kit.zip and unzip it. You get a folder called Roll-Forward.
  2. Already have an empty folder open in VS Code? Use rollforward-kit-contents.zip instead: it unzips straight into that folder, with no extra Roll-Forward folder inside it.
  3. Put your D2L export (.zip) in the folder called put-export-here. Never edit anything in it.

6. Open the folder and test

  1. In VS Code choose File, then Open Folder, and pick Roll-Forward.
  2. In the Codex panel, type this and press Enter:
What skills do you have?

You should see d2l-rollforward in the answer. If you do, you are ready: go to the prompt card.

If the Codex panel opens and then closes by itself, see Codex won’t open. Skip that page if it opens normally.
