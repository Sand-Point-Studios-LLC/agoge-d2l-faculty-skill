Reading your reports

The agent writes three readable pages into ready-to-import. Open them in your browser (double-click) or print them.

PageWhat it is for
COURSE-SETTINGSEverything your course is set up to do: quizzes, assignments, discussions, announcements, gradebook, outside tools. Start with the Patterns section. It names what most items do and the numbered items that differ.
QUALITY-REPORTEvery check, when it last ran, and what it found. “Look at” means read the list. “Not built yet” means the check does not exist, so silence is not a pass.
CHANGESA record of what the tool did, with counts, and the old and new value wherever it changed a setting. It is not a before-and-after list of every date. Older change lists are kept in the history folder.

How to use the patterns

  1. Read the Most common column. If that is what you want, you have nothing to do.
  2. Look at Different on. Each entry is a numbered item that does something else.
  3. If one is a mistake, tell the agent the number and what it should be: “Quiz 11 should be one attempt. Show me first.”

Numbers match the numbered quiz table in the same report.
