Set up

The kit works with an AI assistant that can work inside a folder on your computer. Pick one: ChatGPT (with Codex) or Claude (with Claude Code). Use whichever your institution provides, or the one you already have. Both do the same job here.

Tested routes. We have tested the ChatGPT (Codex) route end to end. The Claude route uses the same kit and Anthropic’s documented steps, but we have not walked it through on a clean machine yet. If a button is named differently on your screen, trust your screen and open an issue on GitHub so we can fix the page.

Read Privacy first: the agent reads whatever files it opens, including quiz questions and answer keys, and sends that text to the AI company. You do this once. Plan on 30 to 45 minutes, plus the download. If anything below does not look like what is on your screen, stop and open an issue on GitHub. (Already use VS Code? There is a VS Code version of these steps.)

1. Get an account and the app

If your institution gives you an AI account for work, use that one and not a personal one. Check its rules in Privacy.

If you chose ChatGPT

  1. You need a ChatGPT account on a plan that includes Codex. If Codex does not appear in the app, ask whoever assigns ChatGPT seats at your institution, or check OpenAI’s plan page.
  2. Windows: open the Microsoft Store, search ChatGPT, click Get.
  3. Mac: download the ChatGPT app from OpenAI’s apps page and drag it to Applications.
  4. Open it and sign in. If it asks which workspace, choose your institution’s.

If you chose Claude

  1. You need a paid Claude plan that includes Claude Code (Pro, Max, Team or Enterprise at the time of writing; check Anthropic’s plan page, because plans change). A free account does not include it.
  2. Go to claude.ai/download and download the Claude desktop app for Windows or Mac. Install it and open it.
  3. Sign in. If your institution has a Claude Team or Enterprise workspace, sign in with that account.

You do not need a GitHub account for any of this.

2. Install Python (the kit’s tools run on it)

  1. Windows: open the Microsoft Store, search Python 3.13, click Get.
  2. Mac: go to python.org/downloads, click the big yellow Download Python button, open the file and click Continue until it finishes.
  3. To check, ask the agent once the folder is open (step 4): “Is Python 3 installed? Tell me the version. On Windows, also install the tzdata package.” The tzdata package lets the date shift keep 11:59 PM at 11:59 PM across daylight saving, and the kit will refuse to move dates without it.

3. Get the kit

  1. Download rollforward-kit.zip and unzip it (Windows: right-click, Extract All; Mac: double-click). Move the result out of Downloads into a folder that OneDrive or iCloud does not sync if you can (a 700 MB export syncs slowly), or into Documents if that is all you have. You get a folder called Roll-Forward.
  2. Mac: Safari may unzip your D2L download by itself. If you see a folder instead of a .zip, delete the folder and download again after turning off Open “safe” files after downloading in Safari Settings, or use Chrome.
  3. Put your D2L export (.zip) in the folder called put-export-here, inside Roll-Forward. Never edit anything in it, and do not unzip it.

4. Open the folder in the app

ChatGPT

  1. In the ChatGPT app, start a new chat in Codex.
  2. Under the message box, click Choose project, then Create project.
  3. Click Add folder, pick the Roll-Forward folder, then click Create project.
  4. The app asks “Trust this folder?” Click Trust folder. This is normal for a folder you unzipped yourself. The box mentions that folder settings can run code automatically; this folder holds the kit’s instructions and its Python tools, which the agent runs for you (you approve each one). Only trust folders from a source you trust; this one came from the download on this site.
  5. Under the message box, check that the permission setting says Ask for approval. That is the default: the agent pauses and asks before it changes or runs anything. Leave it there.

Claude

  1. In the Claude app, open the Code tab.
  2. Choose to work on your own computer (a local session), not a cloud one, so your files stay put.
  3. Choose the folder: pick the Roll-Forward folder itself.
  4. If it asks whether you trust the files in this folder, say yes. This folder holds the kit’s instructions and its Python tools, which the agent runs for you (you approve each one). Only trust folders from a source you trust; this one came from the download on this site.
  5. Check that the permission mode is the one that asks before it runs commands or edits files (usually named “Ask permissions”). Leave it there; do not choose a mode that approves everything automatically.

Prefer a terminal? Install Claude Code from Anthropic’s documentation, open a terminal inside the Roll-Forward folder, and run claude.

5. Test

In the message box, type this and press Enter:

What skills do you have?

You should see d2l-rollforward in the answer. That means the skill loaded. It does not prove Python or the web are working; the next prompts will show that. Go to the prompt card.

If it does not appear, make sure you chose the Roll-Forward folder itself, not a folder above or below it, and that you trusted the folder. Still nothing? Open an issue on GitHub and say what the answer listed.
