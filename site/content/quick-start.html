The one-page version

Steps only. Each links to the detail. Read Privacy once first: the agent reads whatever it opens, including quiz questions and answer keys, and that is sent to the AI provider.

Once

  1. Install the ChatGPT app, sign in with your MSU account, unzip the kit, and install Python (on Windows also the tzdata package). Setup lists each step.

Each term

  1. Export from D2L: Course Admin, Import / Export / Copy Components, Export Components. Tick “Include course files.” Leave unticked anything about students. Do not unzip.
  2. Drag the zip into the folder put-export-here, and open the Roll-Forward folder in the ChatGPT app: start a new chat in Codex, click Choose project, Create project, Add folder (pick Roll-Forward), Create project again, then Trust folder. Full steps are on the Set up page.
  3. In the message box type: Unpack my export and make my course settings report.
  4. Skim the report (how to read it). Ask for changes, ending each with “show me first.”
  5. Type: Move everything to start on [date]. Look up the date on the MSU calendar and show me before you change anything.
  6. Type: Check my package for problems. then Build the import package.
  7. Import into a new, empty shell. Never into a course with students.
  8. Do the three checks that matter most: open one question in each quiz, check the due dates, turn LockDown Browser back on. Then the rest of the checklist.
