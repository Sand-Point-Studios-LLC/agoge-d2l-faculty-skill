FAQ

Do I need a GitHub account?

No. Everything runs on your computer. You need a ChatGPT or Claude sign-in, not GitHub.

Do I need to install anything besides the ChatGPT or Claude app?

Python 3, because the kit's tools are Python. See step 2 on the Set up page. On Windows, also the tzdata package, which the agent can install for you.

Do I need Copilot?

No. If you use the VS Code route, VS Code offers Copilot prominently and some screens will ask you to sign in to it. Ignore those and use the Codex or Claude Code panel with your own sign-in. The app routes never show Copilot.

Will it change my live course?

No. It works on a copy of your export and builds a new package. You import that into a new, empty shell, so the live course is never touched.

What if my quiz already has student attempts?

D2L cannot update a quiz that has attempts by importing. Importing makes a second copy. Those quizzes are repaired by hand in D2L. The agent will tell you which ones.

Is it safe with student information?

Export without student data. The tool looks for obvious student-data files by name and stops if it finds one, but it cannot see inside every file, so the safe step is to untick those boxes when you export. See the Privacy page.

How big an export can it handle?

On our test course, a 780 MB export unpacked in about three seconds and the package rebuilt without trouble. It works on your own computer, so there is no upload limit.

The agent says it cannot do something. Is that true?

Sometimes it is, and the kit says so plainly (Word conversion and module reorganizing are examples). If it says it cannot reach something that sounds basic, ask it to try, and tell us what it says.

Can it look up the academic calendar?

Yes. In our test, Codex reached the web and returned the term dates with a link to the calendar it used. It shows you the dates and the source and waits for you to confirm. If it cannot reach the web, paste the calendar page's text.

Can it change my Word, PowerPoint and PDF files?

Word and PowerPoint: yes, it finds and replaces text inside them (slides, speaker notes, headers) and keeps the formatting. Always open one changed file and look at it, because layout can only be checked by eye. It does not see text inside pictures or old .doc and .ppt files. PDF: no. A PDF cannot be edited safely, so change the Word or PowerPoint file it came from and export a new PDF.

Does the import always work?

We cannot promise that. The tool checks for the things that have broken imports before, and it refuses to build a package with a broken XML file. After any import, check it as a student would.

It said some files are in the package but not linked. What does that mean?

Your course files area holds files that no page uses. They come along in the export. They are not harmful, but they are good candidates for clean-up before you reuse the course.

What does “not built yet” mean in my quality report?

A check we plan but have not written. It is listed so you never mistake silence for a pass.

What is not carried in an export?

LockDown Browser and Monitor, release conditions and special access, the navigation bar (and so FAQ and Links), homepage widgets, the announcement email-copy tick, and anything about people. Your report lists them for you to check by hand.

Can I use my own PowerPoint template?

You can store your own file in the templates folder and the agent will note it. Nothing builds slides yet, so the template is kept for later.

Codex opens and then closes by itself. (ChatGPT only.)

See the Codex won’t open page. It is a leftover database from an older install, and moving it aside fixes it.

Is this an official tool of my school, or of OpenAI or Anthropic?

No. It is an independent open-source skill built by a faculty member and released by Sand Point Studios under the Apache 2.0 licence. It runs inside ChatGPT (Codex) or Claude (Claude Code), which you sign in to yourself. Follow your school’s guidance for your data.

Which should I use, ChatGPT or Claude?

Whichever your school gives you, or the one you already have. The kit is the same for both. We have tested the ChatGPT (Codex) route fully; the Claude route has not been walked through on a clean machine yet, so tell us if a step is off.

How do I get updates?

For now you get a new kit file from the same place you got this one. We will say when there is one.
