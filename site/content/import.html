Import the package into a new shell

Never import into a course students are already in. D2L cannot merge an import into existing content. You would get a second copy of everything beside the first.
  1. Find your new term’s course in D2L. Most schools create an empty shell for every section once you are the instructor of record. If yours is not there, ask your department or your D2L administrator to create one.
  2. Open the new shell. Click Course Admin, then Import / Export / Copy Components.
  3. Choose Import Components, then Upload, and pick the zip from the ready-to-import folder.
  4. Click Import All Components. Wait for the status to read Completed.
  5. Click through the course as a student would, then use the after-import checklist.
  6. When it looks right, make the shell visible to students. The import into a D2L shell has not been tested on this version of the kit, so if you can, try it first in a practice shell (ask your department or Teaching & Learning contact for one) and click through it before the real one.

If the import finishes with warnings, paste them into the message box and ask “explain these.”
