Walk me through my class standards.

The agent asks, one item type at a time, how you want quizzes, due dates, assignments and more to work, and explains what each option does. You can stop after any section.

When Codex asks permission

Codex pauses and shows a box such as “May I allow pip network access and install tzdata?” with the exact command under it. This is the safety catch, and it is working as intended.

  1. Read the command. Commands from this kit start with python (python3 on a Mac, or py on Windows) and name one of its tools (rollforward.py, video_embed.py or diff_exports.py) or a standard package such as tzdata.
  2. If it is what you asked for, click Allow (just that button, not the arrow beside it, which can switch on “always”).
  3. If it deletes files, goes to a website you do not recognize, or is not what you asked for, click Skip, or Explain to have it say what the command does.

After you import

  1. Open one question in every quiz, as a student would see it.
  2. Open one page with an image and one with a video.
  3. Check every due date against your syllabus.
  4. Turn LockDown Browser back on for any quiz that used it.
